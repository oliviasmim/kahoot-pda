# Kahoot PdA

Jogo de quiz estilo Kahoot para a ONG Programadores do Amanhã, usado em aulas e dinâmicas ao vivo.
O projeto será exposto como um MCP server, permitindo criar e gerenciar quizzes diretamente pelo Claude Code.
Os participantes respondem em tempo real enquanto o apresentador controla as perguntas e o placar.
Objetivo: tornar o aprendizado mais interativo e gamificado para os estudantes da ONG.
